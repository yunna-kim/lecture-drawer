전사 모델

전사할 때 사용한 버전은 작업마다 기록됩니다. 새 모델은 시험 결과를 검토한 뒤 기본값으로 적용합니다.

GPU는 음성 전사 우선 · 로컬 요약은 전사가 끝난 뒤 이어갑니다. 요약 중 새 전사가 들어오면 현재 생성 구간을 마친 뒤 양보합니다.

프로그램·라이브러리는 실행 중 자동 업데이트하지 않습니다. 모델 추가·업데이트 방법은 사용법에 있습니다.

완료한 강의를 선택해 로컬 요약을 시험합니다. 이전 결과와 비교하고 내용 검토를 기록하세요. 기존 음성·노트는 바꾸지 않습니다.

시험 서버가 꺼져 있으면 PC에서 tools/start_local_notes.ps1을 실행하세요. 자동 설치·유료 API 전환은 없습니다. 내용 검토 통과도 모델의 기본값 변경과는 별개입니다.
